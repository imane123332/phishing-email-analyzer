Phishing Email Analyzer

A Python tool that reads an .eml file and checks the sender, SPF/DKIM/DMARC, links and attachments. It gives a risk score and a list of indicators of compromise (IOCs). Static analysis only: nothing is opened or executed.

Contenturgency_language (FR, EN, PT, ES, AR) spam_keywords

Each rule counts once per email. Score 20 or more is SUSPICIOUS and 40 or more is MALICIOUS.

Demo

Open the malicious sample report or the benign sample report. The samples are fake emails written for the tests. The live demo runs the real Python code in your browser, so you can try the samples or your own email, and move a slider to see the detection / false-alarm trade-off. Emails are never uploaded anywhere.

Limits

  • Only 150 legitimate emails per set, so 1 false alarm could mean a true rate of roughly 0.1% to 3.7%.
  • The legitimate emails are promotions, updates and social mail from one mailbox, not personal or work mail.
  • About one third of the phishing is missed: plain-text or image-only scams with no technical red flag.
  • Next step: URL and IP reputation lookups (VirusTotal, AbuseIPDB) and MITRE ATT&CK tagging.
