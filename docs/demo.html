2. How good is it?

Move the slider to change the alert threshold. These numbers were measured on a separate test set that was not used to tune the rules: 1,500 real phishing emails (phishing_pot) and 150 legitimate emails from one Gmail inbox.

Be careful with these numbers.
  • Only 150 legitimate emails: 1 false alarm could mean a true rate between about 0.1% and 3.7%.
  • The legitimate emails are promotions, updates and social mail from one inbox, not personal or work mail.
  • About a third of phishing is missed. Try the "A case it misses" sample: a plain-text scam with no technical red flag.
  • The default threshold (20) was chosen on the tuning set, before the test set was run once.
